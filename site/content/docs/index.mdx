Aerostack2 is an open source software framework that helps developers design and build the control
architecture of aerial robotic systems, integrating multiple heterogeneous computational solutions —
computer vision algorithms, motion controllers, self-localization and mapping methods, motion
planning algorithms and more.

### Math

Replaces `.. math::` and the `:math:` role, rendered with KaTeX. Inline math uses `$…$` and display
math uses `$$…$$`.

Instantaneous mass is thrust over vertical acceleration, where $T$ is the thrust and $a_z$ the
vertical acceleration in $m/s^2$:

$$
m_{inst} = \frac{T}{{a_z}}
$$

The force error is the difference between commanded and measured force:

$$
F_{error} = F_{cmd} - F_{meas} \quad\text{where}\quad F_{meas} = m \cdot {a}_z
$$

### Code blocks

Replaces `.. code-block::`, rendered with the Fumadocs `CodeBlock` component. The copy button is
built in, so `sphinx-copybutton` is no longer needed.

`title` covers the 10 places the old docs used `:caption:`, and `lineNumbers` turns on numbering:

```bash title="launch_simulation.sh" lineNumbers
ros2 launch as2_gazebo_assets launch_simulation.py \
  use_sim_time:=true \
  simulation_config_file:=config/world.json
```

Consecutive blocks tagged with `tab` become a tabbed group — useful for the install pages, which
currently repeat themselves for each method:

```bash tab="Binary"
sudo apt install ros-humble-aerostack2
```

```bash tab="Source"
vcs import src < aerostack2.repos
colcon build --symlink-install
```

Shiki has no SDFormat grammar, so the old `.. code-block:: sdf` blocks become `xml`:

```xml title="model.sdf"
<sdf version="1.9">
  <model name="quadrotor">
    <link name="base_link" />
  </model>
</sdf>
```

Use `noCopy` on blocks that shouldn't be copied, such as sample output:

```console noCopy
[INFO] [as2_platform]: Platform is ready
```
